Modelos de Redes

Los modelos de red permiten organizar y entender cómo se comunican las computadoras dentro de una red. Su propósito central es formalizar y estructurar la interacción entre sistemas de computación heterogéneos, garantizando la interoperabilidad sin importar el fabricante, el hardware o el sistema operativo empleado.

¿Qué es una Red?

Una red es un conjunto de nodos (routers, servidores, computadoras) y arcos (cables de cobre, fibra óptica, ondas de radio) que conectan ciertos pares de nodos para transportar datos y compartir recursos de manera eficiente.

Compartir Recursos

Permite intercambio de archivos, impresoras y conexiones a Internet.

Tolerancia al Fallo

Protocolos como OSPF y BGP mantienen la conectividad automáticamente.

Escalabilidad

Posibilidad de agregar dispositivos sin rediseñar toda la red.

Topologías de Red

La topología define la estructura de una red y se divide en física (disposición espacial de cables y dispositivos) y lógica (la ruta que siguen los datos a través de los medios)

Protocolo STP

El protocolo STP (Spanning Tree Protocol, IEEE 802.1D) es la implementación práctica del árbol de expansión. Su función es evitar bucles y tormentas de broadcast en redes con switches conectados de forma redundante, desactivando automáticamente los caminos sobrantes y manteniéndolos exclusivamente como respaldo.

Principios de Diseño de Capas

Identidad Funcional

Cada capa debe cumplir funciones específicas y diferenciadas, evitando superposición de tareas.

Fronteras Claras

Las interfaces entre capas deben minimizar la complejidad y el intercambio innecesario de información.

Independencia Tecnológica

Cada capa debe poder modificarse sin afectar el funcionamiento interno de las demás.

Ocultamiento de Información

Las capas superiores utilizan servicios abstractos sin conocer los detalles internos de implementación.

Primitivas de Servicio y QoS

Un servicio es un conjunto de operaciones o primitivas que una carpeta inferior pone a dispocicion de la capa inmediatamente superior para interactuar y transferir informacion

Tipos de Primitivas

Orientado a Conexión:
Requiere una secuencia rigurosa de cuatro primitivas: Request, Indication, Response y Confirm.

Sin Conexión:
Prescinde de negociación previa. Usa solo DATA.request y DATA.indication

Parámetros Críticos de QoS

Las primitivas permiten negociar parámetros contractuales de rendimiento de red:

- Ancho de banda mínimo(bps)
- Retardo de tránsito máximo (latencia)
- Jitter máximo (variación del retardo)
-Probabilidad de pérdida de paquetes

Modelo OSI

El modelo Open Systems Interconnection (OSI) es un estándar conceptual creado por la ISO que divide la comunicación de red en siete capas abstractas apiladas para permitir la interoperabilidad de sistemas heterogéneos.

Modelo TCP/IP

TCP/IP es un protocolo de enlace de datos que se usa en Internet para que los ordenadores y otros dispositivos envíen y reciban datos.
TCP/IP son las siglas en inglés de Transmission Control Protocol/Internet Protocol (protocolo de control de transmisión/protocolo de Internet).
Posibilita que los dispositivos conectados a Internet se comuniquen entre sí en varias redes.

OSI vs TCP/IP

Tanto el modelo OSI como el TCP/IP están diseñados para proporcionar una estructura para pensar y debatir sobre el tráfico de red. Sin embargo, los dos modelos tienen algunas diferencias significativas


Capas

El modelo OSI tiene siete capas diferentes construidas en torno a las distintas funciones que debe realizar el tráfico de red.

El modelo TCP/IP tiene un total de cuatro capas que están ligadas directamente a protocolos específicos que existen en el tráfico de red.

Aplicabilidad en el Mundo Real

El modelo OSI está diseñado como un modelo conceptual de referencia, lo que significa que no se corresponde directamente con protocolos reales.

El modelo TCP/IP se basa en protocolos estándar utilizados para crear conexiones de red.

Dependencia del Protocolo

El modelo TCP/IP se basa en protocolos específicos diseñados para lograr objetivos concretos.

El modelo OSI es independiente del protocolo, permitiendo el uso de cualquier pila de protocolos.

Tipos de Tráfico

El modelo OSI admite tráfico orientado a conexión y tráfico sin conexión.

El modelo TCP/IP está diseñado específicamente para tráfico TCP orientado a conexión.
